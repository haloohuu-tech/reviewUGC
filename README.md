# 内容安全运营后台原型

直接双击 `index.html` 即可打开，不需要安装依赖或启动服务。

本期 MVP 页面：审核任务、任务查询、策略中心。

主要交互：

- 先发后审：机审通过后自动发布，不需要人工审核
- 先审后发：机审通过后进入人工二审，通过后才发布
- 审核任务搜索、筛选与人工二审详情
- 审核任务和任务查询均支持时间范围筛选，默认查询近 7 天
- 审核范围覆盖头像、昵称、用户简介、AI 音乐评论与回复
- 图片内容放大直观展示，昵称/简介/评论最多两行省略并支持悬浮查看完整详情
- 审核内容固定展示用户 ID
- 勾选任务后支持批量审核通过或批量驳回，批量驳回必须选择原因
- 审核任务不采用领取或个人任务机制；表头支持一键选中当前页面全部任务
- 用户更新或删除待审内容时，任务从审核队列移除；任务查询保留“用户更改”记录并锁定操作
- 全任务查询与已通过内容的运营直接驳回
- 任务查询覆盖需要运营追溯的用户上传内容，包括“不检查”直发记录，并展示人工审核人员及其后台管理账号
- “不检查”内容不调用机审、不进入审核任务表，写入业务库后立即公开并进入任务查询
- 运营复审通过后的内容仍可再次直接驳回；用户更新或删除后原记录变为“用户更改”且不可编辑
- 驳回后任务锁定，不支持再次编辑或改判
- 地区策略新建、编辑与策略释义
- 使用国家采用下拉单选；同一国家可配置多个策略，但审核范围不能重叠
- 已被同一国家其他策略占用的审核范围以置灰勾选展示，且不可再次选择
- 未配置策略的国家或未配置的审核范围不触发机审或人审，按“不检查”处理并进入任务查询；平台默认资料等免审内容不进入任务查询
- 地区策略保存后统一立即生效；生效时间仅作为后端记录展示
- 审核任务仅展示用户上传时间（精确到分钟），不展示 SLA、超时及人工通过率
- 全局快速搜索（`⌘/Ctrl + K`）

当前为静态高保真产品原型，页面中的数据均为演示数据，未连接真实接口。
